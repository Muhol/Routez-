Supabase data-integrity notes
Before entering this data into Supabase, keep the following distinctions:
- Routes: Each route record contains its route name and route number.
- Stages: Each stage belongs to a route and has a stage order, stage name, and GPS location when supplied.
- Roads: Each road belongs to the route-level road list. The spreadsheet does not establish a direct relationship between a particular road and a particular stage.
- Missing values: [BLANK IN SOURCE] is a transcription marker, not a literal database value. Use NULL or another representation only according to your schema and import rules.
- GPS coordinates: The coordinates above remain in their original combined latitude-and-longitude form. If your Supabase schema uses separate numeric columns, split them during a controlled import without rounding them.
- Route identifiers: Route numbers such as 46, 2, 7c, and 8 should be handled according to the existing schema. If the route number is a text identifier, use a text column so alphanumeric values such as 7c are supported.
- Road ordering: The road list order is preserved from the source. The order does not imply a mapping to stage order.
